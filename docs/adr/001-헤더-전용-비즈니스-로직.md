# ADR-001: 헤더 전용 비즈니스 로직

## 상태

수락됨

## 맥락

C++ 프로젝트에서 비즈니스 로직을 `.hpp`(헤더)와 `.cpp`(구현) 파일로 분리할지 결정이 필요했습니다.

## 결정

모든 서비스, 유틸리티, DTO 클래스를 `.hpp` 헤더 파일에만 구현합니다. `CMakeLists.txt`의 `add_executable`에는 `.cpp` 파일만 포함합니다.

## 근거

- 빌드 설정이 단순해짐 (새 소스 파일 등록 불필요)
- oatpp 프레임워크의 매크로 기반 패턴(`ENDPOINT_ASYNC`, `OATPP_COMPONENT`)과 자연스럽게 맞음
- 소규모 프로젝트에서 헤더/구현 분리의 오버헤드를 줄임

## 결과

- **긍정적**: 새로운 서비스/유틸리티 추가 시 `.hpp` 파일만 생성하면 됨
- **부정적**: 대규모 변경 시 컴파일 시간 증가 (헤더 변경이 의존하는 모든 파일 재컴파일 유발)
- **제약**: `CMakeLists.txt`에 `.hpp` 파일을 절대 추가하지 않는 규칙 준수 필요
