# ADR-003: 테스트에 oatpp 가상 네트워킹 사용

## 상태

수락됨

## 맥락

API 통합 테스트를 실행하려면 HTTP 서버가 필요합니다. 실제 TCP 소켓을 사용할 수도 있고, oatpp의 가상 네트워크 인터페이스를 사용할 수도 있습니다.

## 결정

테스트 인프라에서 실제 TCP 소켓 대신 oatpp의 가상 네트워크 인터페이스(`oatpp::network::virtual_::Interface`)를 사용합니다. 데이터베이스는 실제 PostgreSQL을 사용합니다.

## 근거

- 실제 포트 바인딩 불필요 → CI에서 포트 충돌 없음
- 인메모리 통신으로 테스트 속도 향상
- 네트워크 관련 불안정성(flaky) 제거
- 실제 DB를 사용하므로 SQL 쿼리와 ORM 동작을 실제로 검증

## 결과

- **긍정적**: CI 환경에서 안정적으로 실행됨
- **긍정적**: 포트 설정 없이 테스트 가능
- **부정적**: `TestComponent.hpp`에 가상 네트워크 전용 DI 설정이 필요함
- **제약**: `TestDatabaseComponent.hpp`는 `DatabaseComponent.hpp`의 멤버 선언 순서를 정확히 복제해야 함 (C++ 멤버 초기화 순서 의존성)
