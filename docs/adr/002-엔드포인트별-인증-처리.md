# ADR-002: 엔드포인트별 인증 처리 (미들웨어 없음)

## 상태

수락됨

## 맥락

HTTP API에서 인증을 처리하는 두 가지 접근 방식이 있습니다: 중앙 미들웨어 vs 엔드포인트별 수동 확인.

## 결정

인증 미들웨어를 사용하지 않습니다. 각 엔드포인트가 `UserAuth::fromAuthHeader(request)`를 직접 호출하여 인증을 확인합니다. `ua.id == 0`이면 비인증 상태입니다.

## 근거

- 각 엔드포인트의 인증 요구사항이 코드에서 바로 보임 (명시적)
- `publicMode` 플래그에 따라 일부 엔드포인트(GetArticle, NewComment, DelComments)의 인증 동작이 달라지는데, 미들웨어로는 이 조건부 로직이 복잡해짐
- oatpp 1.3.0의 비동기 코루틴 패턴에서 미들웨어 체인 구현이 복잡함

## 결과

- **긍정적**: 엔드포인트별 인증 요구사항이 투명하게 드러남
- **긍정적**: `publicMode` 조건부 인증이 자연스럽게 구현됨
- **부정적**: 인증 코드가 모든 인증 필요 엔드포인트에 반복됨
- **패턴**: `auto ua = UserAuth::fromAuthHeader(request); if (ua.id == 0) { return mkErrMsg("Login first."); }`
