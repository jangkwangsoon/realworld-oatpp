# ADR-004: oatpp 1.3.0 버전 고정

## 상태

수락됨

## 맥락

oatpp 프레임워크는 버전 간 API 호환성이 보장되지 않습니다. 프로젝트가 안정적으로 동작하는 버전을 고정할 필요가 있습니다.

## 결정

oatpp, oatpp-zlib, oatpp-postgresql 모든 모듈을 1.3.0 버전으로 고정합니다. 업그레이드하지 않습니다.

## 근거

- 1.3.0에서 모든 기능이 정상 동작함
- oatpp의 메이저/마이너 업데이트는 비동기 API 변경을 포함할 수 있음
- `utility/install-oatpp-modules.sh` 스크립트가 1.3.0 태그를 명시적으로 체크아웃함

## 결과

- **긍정적**: 빌드 재현성 보장
- **긍정적**: CI에서 모듈 캐싱이 안정적으로 동작함
- **부정적**: 새 기능이나 보안 패치를 자동으로 받을 수 없음
- **제약**: oatpp 모듈 업그레이드 시 전체 API 호환성 검증 필요
