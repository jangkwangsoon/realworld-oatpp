# ADR-005: publicMode 설정을 통한 조건부 인증 완화

## 상태

수락됨

## 맥락

일부 사용 시나리오에서는 인증 없이도 게시글과 댓글에 접근할 수 있어야 합니다. 모든 엔드포인트에 일괄 적용하지 않고 선택적으로 인증을 완화할 방법이 필요했습니다.

## 결정

`config.json`의 `server.publicMode` 플래그를 사용하여 다음 3개 엔드포인트에서 비인증 접근을 허용합니다:
- `GET /api/articles/{slug}` — 게시글 조회
- `POST /api/articles/{slug}/comments` — 댓글 작성
- `DELETE /api/articles/{slug}/comments/{cid}` — 댓글 삭제

## 근거

- 데모 또는 공개 읽기 전용 배포에 유용
- 설정 파일 변경만으로 동작 전환 가능 (코드 변경 불필요)
- 영향 범위를 3개 엔드포인트로 한정하여 보안 리스크 최소화

## 결과

- **긍정적**: 런타임에 인증 정책 변경 가능
- **부정적**: 엔드포인트별 인증 처리(ADR-002)와 결합되어, publicMode 확인 코드가 3곳에 분산됨
- **제약**: publicMode 활성화 시 댓글 작성자가 `id=0`(익명)으로 기록될 수 있음
